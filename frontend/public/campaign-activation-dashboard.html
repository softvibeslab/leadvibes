SendGrid · API key + remitente

Usa SendGrid para email masivo. La documentación oficial indica que debes autenticar con API key y verificar tu identidad de remitente antes de enviar.

  1. Entra a SendGrid Console → Settings → API Keys y crea una API key de envío.
  2. Para pruebas rápidas, ve a Settings → Sender Authentication → Verify a Single Sender y verifica un solo email.
  3. Para producción, usa Domain Authentication y configura los DNS que SendGrid te entregue.
  4. En Rovi pega la API key, el email remitente verificado y el nombre remitente.

Twilio · Account SID, Auth Token y número SMS

Twilio usa Account SID y Auth Token para autenticar requests. Para SMS necesitas además un número con capacidad de mensajería.

  1. Entra a Twilio Console. En la primera pantalla, bajo Account Info, copia tu Account SID y Auth Token.
  2. Abre Phone Numbers y compra o selecciona un número con capacidad SMS.
  3. Si tu país o tipo de número exige requisitos regulatorios, complétalos antes de enviar.
  4. En Rovi pega SID, token y número en formato internacional.
Dónde ver SID y Token Phone Numbers Abrir Twilio Console

Twilio WhatsApp · Sandbox o sender productivo

Twilio recomienda dos caminos: Sandbox para pruebas rápidas y Self Sign-up para un sender real vinculado a tu negocio y Meta.

  1. Para prueba rápida, activa Twilio Sandbox for WhatsApp y haz que cada destinatario mande join <código> al número del sandbox o escanee el QR.
  2. Para producción, entra a Messaging → Senders → WhatsApp Senders → Create new sender y completa el Self Sign-up con Meta.
  3. Si registras un número Twilio, copia el número desde la consola y úsalo durante el flujo de alta del sender.
  4. En Rovi pega el sender final como whatsapp:+1415... o solo +1415....

Vapi · API key, Assistant ID y Phone Number ID

Vapi requiere tres datos en Rovi: tu API key, el Assistant ID y el Phone Number ID con el que hará o recibirá llamadas.

  1. Entra a dashboard.vapi.ai y desde tu perfil abre Vapi API Keys para copiar tu Private API Key.
  2. Ve a Assistants, crea o abre un asistente, publícalo y copia el Assistant ID desde la URL o el detalle.
  3. Ve a Phone Numbers, crea un número gratis en EE. UU. o importa uno desde Twilio, y copia el Phone Number ID.
  4. Pega esos tres valores en Rovi y usa “Probar Conexión”.
