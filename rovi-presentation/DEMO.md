## 🌟 Efectos Implementados

### 3D (Three.js + R3F)
- ✨ **Sparkles** - Partículas brillantes flotantes
- ⭐ **Stars** - Campo estelar de fondo
- ☁️ **Cloud** - Nubes etéreas semitransparentes
- 🎈 **Float** - Flotación suave de objetos
- 💡 **Emissive** - Materiales que emiten luz
- 🔄 **OrbitControls** - Rotación interactiva

### UI (Framer Motion + CSS)
- 📊 **Transiciones** - Slide-in/slide-out con spring
- 🌈 **Gradientes** - Texto con gradiente animado
- 💫 **Glows** - Sombras y brillos dinámicos
- 🎯 **Progress Bar** - Indicador de progreso suave
- 📱 **Backdrop Blur** - Efecto cristal esmerilado

## 🚀 Quick Start

```bash
cd rovi-presentation

# Opción 1: Setup automático
./setup.sh

# Opción 2: Manual
npm install
npm run dev
```

## 🎬 Storytelling - El Arco Narrativo

### 1. El Despertar (Slides 0-1)
- **Misterio**: La lámpara flotante
- **Revelación**: El genio emerge
- **Promesa**: "No soy un asistente, soy tu co-piloto"

### 2. El Poder (Slides 2-3)
- **El Ejército**: 4 familias de agentes
- **La Multiplicación**: ×16 amplificación cognitiva
- **La Diferencia**: No reemplazo, sino potenciación

### 3. La Estrategia (Slide 4)
- **La Matriz**: Eisenhower optimizada por IA
- **El Tiempo**: 30% hacer, 40% planificar, 20% delegar, 10% soltar
- **El Método**: Priorización inteligente

### 4. El Camino (Slide 5)
- **Mes 1**: Fundación y descubrimiento
- **Mes 2**: Aceleración y dominio
- **Mes 3**: Maestría e independencia

### 5. La Transformación (Slide 6)
- **La Promesa**: "Serás la versión amplificada de ti mismo"
- **El CTA**: "Comienza tu transformación"
- **El Futuro**: Más estratégico, más creativo, más libre
