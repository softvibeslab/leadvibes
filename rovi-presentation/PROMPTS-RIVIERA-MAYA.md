## 📝 Usage Notes

### For Midjourney:
- Use `--ar 16:9` for slides
- Use `--ar 4:5` for agent portraits
- Use `--style raw` for photorealistic results
- Use `--niji 6` for character illustrations
- Use `--stylize 250-750` for more artistic freedom

### For DALL-E:
- Be specific about "photorealistic" or "3D render"
- Mention lighting: "golden hour", "cinematic", "warm"
- Specify style: "professional photography", "infographic"

### For Stable Diffusion:
- Use detailed prompts for best results
- Include negative prompts for unwanted elements
- Adjust CFG scale for creativity vs accuracy
