Flujos clave

Secuencias para probar cada modulo sin perderse entre rutas.

1. Agente estratega y dashboard dinamico

Flujo principal para la demo de decision ejecutiva.

1Login con un usuario ROVI interno, recomendado admin@rovicrm.com.
2Abrir /database-chat y dejar seleccionado el modo Dashboard.
3Preguntar por ruta critica, KPIs, plan de accion, agentes o marketplace.
4El backend llama /api/strategy-playground/run, consulta metricas, Graphify y knowledge base.
5La UI renderiza canvas tipo Grafana, cards del chat, inspector y export JSON.

2. Configurar agentes por rol

Flujo para ajustar modelo, proveedor, prompt y base de conocimiento.

1Entrar a /rovi/ai-control.
2En Agentes, elegir scope: ROVI, COPIM, inmobiliaria o broker.
3Configurar proveedor: chat.z, modelo glm-5 u Ollama local.
4En Base, subir archivos o indexar grafo ROVI generado con Graphify.
5En Prueba, ejecutar una consulta y revisar costo, tokens, latencia y fuentes.

3. Marketplace digital y Agent Skills

Flujo comercial para monetizar productos, servicios y habilidades de IA.

1Abrir marketplace segun rol: ROVI, COPIM, miembro, inmobiliaria o broker.
2Filtrar por producto digital, servicio profesional o Agent Skill.
3Comprar o instalar en modo demo.
4Backend registra transaccion, comisiones y entitlement.
5El usuario descarga archivo, ve skill instalada o sigue el servicio contratado.

4. COPIM por capas

Separacion de consejo, asociacion local y miembro.

1Consejo nacional: dashboard, asociaciones, socios, cursos, eventos y marketplace.
2Asociacion local: perfil, socios propios, cobranza, eventos, campanas e inventario.
3Miembro: portal personal, membresia, pagos, cursos, eventos, comunidad y marketplace.
4El agente adapta el contexto con copim_council, copim_association o copim_member.

5. VibeLab comercial

Flujo experimental para validar ofertas y canales.

1Entrar a /rovi/vibe-lab.
2Crear o revisar audiencias, segmentos y grupos.
3Configurar oferta, variantes, copy y CTA.
4Generar posts o acciones semi-manuales.
5Registrar metricas: replies, clicks, pagos, revenue, quejas y aprendizajes.

6. Broker e inmobiliaria

Flujo de CRM clasico conectado con IA y marketplace.

1Broker entra a pipeline, productos, campanas, calendario y marketplace.
2Manager/inmobiliaria ve brokers, gamificacion, analytics y tablero de equipo.
3El agente filtra leads por tenant y asignacion para proteger datos.
4Marketplace ofrece plantillas, servicios y skills para acelerar ventas.
