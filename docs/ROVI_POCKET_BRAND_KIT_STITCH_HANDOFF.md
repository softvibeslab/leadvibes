## Nota importante sobre el sistema visual

El proyecto adopto un `designTheme` inicial claro a nivel proyecto por la primera generacion. Sin embargo, las pantallas posteriores y recomendadas usan sistemas oscuros tipo `ROVI Tactical Noir` y `ROVI Tactical HUD`, que son los que mejor representan la identidad deseada.

En terminos practicos:

- tomar como canon visual las seis pantallas preferidas,
- no usar la primera board clara como fuente principal de decisiones,
- si el equipo quiere dejar el proyecto completamente limpio, conviene hacer una pasada posterior para normalizar el tema del proyecto y depurar la exploracion inicial.

## Como usar este handoff

### Si el equipo sigue en Stitch

- usar `ROVI Pocket Foundations` como pagina de arranque,
- derivar desde `ROVI Social Profile System` los assets de portada, avatar y bio visual,
- derivar desde `ROVI Pocket Template System` las plantillas por formato,
- derivar desde `ROVI Pocket Webinar Launch Kit` los assets de campana,
- usar `ROVI Pocket Webinar Registration` como base de landing o hero de registro,
- usar `ROVI Pocket Mobile Outreach Pack` como fuente para export de historias y estados.

### Si el equipo migra a Figma o Canva

Usar este orden:

1. migrar `ROVI Pocket Foundations`,
2. migrar `ROVI Social Profile System`,
3. migrar `ROVI Pocket Template System`,
4. migrar `ROVI Pocket Webinar Launch Kit`,
5. migrar `ROVI Pocket Webinar Registration`,
6. migrar `ROVI Pocket Mobile Outreach Pack`.
