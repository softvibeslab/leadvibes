# DIFERENCIAS CLAVE ENTRE NIVELES

# VISIBILIDAD

# - Nivel 2: Ve SOLO SUS prospects y SUS métricas

# - Nivel 1: Control TOTAL (reasignar prospects, editar gamificación, configurar integraciones)
# - Nivel 2: Control de SUS prospects (mover etapas, editar info, crear tareas)
# - Nivel 3: Control de campañas (crear, editar, pausar, ver resultados)

# RESPONSABILIDAD
# - Nivel 1: Responsabilidad ESTRATÉGICA (decidir dónde invertir, qué campañas escalar)
# - Nivel 2: Responsabilidad de CIERRE (convertir prospects en clientes)
# - Nivel 3: Responsabilidad de GENERACIÓN (crear leads calificados para Sales)

# ===================================================================
# TÉRMINOS CLAVE
# ===================================================================

# Prospecto: Cliente potencial B2B (empresa interesada en comprar)
# Lead: Persona que mostró interés (todavía no es cliente)
# Pipeline: Embudo de ventas (proceso desde interés hasta compra)
# Score: Número 0-100 que dice qué tan probable es que compren
# Discovery Call: Primera llamada para conocer al prospecto
# Demo: Presentación del producto (30-45 minutos)
# Propuesta: Oficial de precios y servicios
# Negociación: Discutir detalles finales del contrato
# Cierre: Momento en que firman y pagan
# Onboarding: Primeros 30 días del cliente (aprendizaje del sistema)
# Churn: Tasa de cancelación (clientes que se van)
# CAC: Costo de Adquisición de Cliente (cuanto cuesta conseguir uno)
# MRR: Monthly Recurring Revenue (ingreso mensual recurrente)
# ROI: Return on Investment (retorno de inversión)
# ICP: Ideal Customer Profile (perfil de cliente ideal)
# Gamification: Sistema de puntos y recompensas
# Cross-level: Entre departamentos (Marketing + Sales)

# ===================================================================
# RESUMEN FINAL
# ===================================================================

# Nivel 1 (Admin): Estrategia y Control. Ve todo, decide todo, controla todo.
# Nivel 2 (Sales): Cierre y Conversión. Gestionan prospects, cierran ventas, compiten por bonos.
# Nivel 3 (Marketing): Generación y Demanda. Crean campañas, generan leads, nutren prospects.
